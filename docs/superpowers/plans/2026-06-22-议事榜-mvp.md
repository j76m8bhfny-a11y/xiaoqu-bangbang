# 小区议事榜 - 阶段 1 MVP 实现计划

**目标：** 实现议事榜功能（议题-事件聚合、赞踩评论评分、admin 管理、mock AI），不接真实 AI

**架构：** 新增 `topics` API 模块（NestJS），扩展 Event 模型加 `topicId`/`aiComment`；小程序新增议事榜 tab + 小区广场合并 tab；admin 后台新增议事管理菜单页；shared 包新增 Topic 相关 DTO 和枚举

## 全局约束

- 复用现有 `AiReviewService` 做内容审核（mock 关键词匹配）
- 复用现有 `NotificationsService.create()` 发通知
- 议事类事件只用 `pending_review → open → rejected` 3 种状态
- 议题 `communityId` 必填，不跨小区
- 评论嵌套最多 2 层，带图最多 9 张
- 瀑布流用方案 B（双列 View + JS 分配），抽成通用组件
- TDD：每个 API 端点先写失败测试，再写实现
- 频繁提交：每个 Task 完成后提交一次

```typescript
async suggestTopics(communityId: string, title: string, description: string) {
  const topics = await this.prisma.topic.findMany({ where: { communityId, status: 'open' } });
  const content = (title + description).toLowerCase();
  const scored = topics.map(t => {
    const tokens = new Set(t.title.toLowerCase().split(/\s+/));
    const matchCount = [...tokens].filter(w => content.includes(w)).length;
    return { topicId: t.id, title: t.title, similarity: tokens.size ? matchCount / tokens.size : 0 };
  });
  return scored.sort((a, b) => b.similarity - a.similarity).slice(0, 3);
}
```
