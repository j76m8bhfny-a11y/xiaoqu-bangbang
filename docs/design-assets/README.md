## 三、使用方式

### SVG 图标在小程序中的引用

SVG 文件可直接放入 `apps/miniapp/src/assets/icons/` 目录，通过以下方式使用：

```tsx
// 方式1：直接 import（Taro 支持）
import tabHome from '@/assets/icons/tab-home.svg';

// 方式2：SVG mask 方式（推荐，支持颜色控制）
// 在 SCSS 中：
// .icon-tab-home {
//   -webkit-mask: url('@/assets/icons/tab-home.svg') no-repeat center;
//   mask: url('@/assets/icons/tab-home.svg') no-repeat center;
//   background: currentColor;
// }
```

### PNG 图片引用

```tsx
import illusHero from '@/assets/images/illus-hero.png';

<Image src={illusHero} mode="aspectFill" />;
```

## 四、补充说明

1. **未导出的图标**：二级页面中大量复用的图标（BackBtn 返回箭头、SBICons 状态栏图标等）未一一导出，因为它们在多个页面中重复出现，只需导出一份即可。如需这些图标，可在设计稿中按节点 ID 导出。

2. **图标颜色**：导出的 SVG 使用设计稿中的固定颜色。如需通过 CSS `currentColor` 控制颜色，需手动将 SVG 中的 `fill` 属性改为 `currentColor`。

3. **Design Token 对应关系**：
   - 主色绿 `#5B9E6F` → 变量 `primary`
   - 强调橙 `#E89B6C` → 变量 `accentDeep`
   - 文字深灰 `#2D3436` → 变量 `text`
   - 次要文字 `#636E72` → 变量 `textSecondary`
